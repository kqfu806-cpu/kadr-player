# Курымдык — локальный медиаплеер с клипами

Тёмная тема, русский интерфейс, Windows 11. Если у трека есть **официальный видеоклип**, плеер находит его на YouTube и встраивает через IFrame API. Если клипа нет — показывает обложку (Deezer → MusicBrainz/Cover Art Archive). Кнопка **Качество** проверяет теги, длительность и битрейт локальных аудиофайлов; замена возможна только после подтверждения, а исходный файл перемещается в `archive/censored/`.

Все решения ИИ идут **только** на локальную [Ollama](https://ollama.com) (`http://127.0.0.1:11434`). Для дополнительной информации об исполнителях доступна необязательная интеграция Last.fm; музыкальные файлы туда не отправляются.

## 2. Установка

### Python

Нужен **Python 3.10+** (рекомендуется 3.13).

1. Скачайте с https://www.python.org/downloads/windows/
2. При установке отметьте **Add python.exe to PATH**.
3. Проверка в `cmd`:

```bat
python --version
```

`run.bat` сам создаст `venv` и поставит пакеты из `requirements.txt`:

- FastAPI + Uvicorn — веб-сервер
- httpx — HTTP-клиент к YouTube / Deezer / MusicBrainz / Ollama
- mutagen — чтение тегов
- Pillow — плейсхолдеры обложек
- yt-dlp — поиск кандидатов и получение аудио только после подтверждения замены

Для ручного запуска из PowerShell:

```powershell
python -m venv venv
.\venv\Scripts\python.exe -m pip install -r requirements.txt
.\venv\Scripts\python.exe -m uvicorn backend.main:app --reload --host 127.0.0.1 --port 8000
```

Для разработки установите также тестовые зависимости из `requirements-dev.txt`. Настройки Last.fm задаются в `.env` на основе `.env.example`; остальные сервисы не требуют ключей.

### Ollama (локальный ИИ)

1. Установите Ollama: https://ollama.com/download
2. Убедитесь, что сервис слушает `http://127.0.0.1:11434`.
3. Подтяните модели (уже есть у вас — шаг можно пропустить):

```bat
ollama pull deepseek-r1:8b
ollama pull llava:7b
ollama pull nomic-embed-text
```

Роли моделей:

| Модель | Зачем |
|---|---|
| `nomic-embed-text` | семантически сравнивает название трека с кандидатами YouTube |
| `deepseek-r1:8b` | арбитр: выбирает **один** официальный клип или говорит, что клипа нет; парсит «грязные» имена файлов |
| `llava:7b` | визуально проверяет найденную обложку |

Если Ollama выключена, плеер **всё равно работает**: поиск клипа идёт по эвристикам (official video / канал / длительность).

### Запуск

Двойной щелчок по `run.bat` (файл **только на латинице** — `cmd.exe` ломает кириллицу в `.bat`).

```bat
run.bat
```

Скрипт сам создаст `venv`, поставит пакеты **внутрь него** и запустит сервер через `venv\Scripts\python.exe` (не через глобальный Python из Microsoft Store).

Браузер откроет http://127.0.0.1:8000

В интерфейсе: **Папка…** → выберите каталог с музыкой → клик по треку.

Для быстрой проверки в комплекте есть `music_demo/` (два коротких WAV):  
«Кино - Группа крови» (клип должен найтись) и «Северная комната - Черновик 14» (клипа нет → плейсхолдер).

### Last.fm (необязательно)

Для Last.fm создайте бесплатный API key, затем задайте `LASTFM_API_KEY` в переменной окружения или в локальном `.env` в корне проекта (шаблон — `.env.example`). Не коммитьте `.env`. Без ключа запросы без кэшированных данных вернут HTTP 503, приложение продолжит работать.

- `GET /api/lastfm/similar/{artist}?limit=20`
- `GET /api/lastfm/top/{artist}?limit=10`
- `GET /api/lastfm/info/{artist}`
- `GET /api/artist/{name}` — локальная библиотека, биография, теги, похожие и топ-треки Last.fm, недавние релизы MusicBrainz

Ответы кэшируются локально в `.tools/lastfm_cache/` на 24 часа; при сбое API или лимите запросов доступен устаревший кэш возрастом до 7 дней. Журнал запросов — `.tools/lastfm.log`; backend предупреждения и ошибки записывает с ротацией в `cache/errors.log`. Если SQLite временно занята, API вернёт 503 с просьбой повторить запрос.

Профиль исполнителя открывается нажатием на артиста в боковой панели. Внешние топ-треки ведут на их страницы Last.fm. Загрузка коммерческих записей через сторонний загрузчик в профиль не добавлена; локальные треки доступны прямо в плеере.

### Статистика прослушиваний

Кнопка «Статистика» показывает дневные, недельные, месячные и общие итоги, топы, почасовой/дневной график и жанры Last.fm. Графики рисуются локально на Canvas/CSS, без CDN и внешней зависимости. Засчитывается сессия длительностью более 30 секунд; история хранится в локальной `cache/stats.sqlite3`. CSV можно выгрузить из панели статистики. Время событий хранится и отображается в UTC.

### Моя волна

Кнопка «Моя волна» включает непрерывную локальную очередь: примерно 60% часто слушаемого и 40% редкого, давно не включавшегося или похожего по вкусу. Эмбеддинги `nomic-embed-text` вычисляются пакетами в фоне, кэшируются в `cache/stats.sqlite3` и не пересчитываются для уже известных треков. После первого запуска волны фоновая задача раз в сутки проверяет новые записи; временная недоступность модели не блокирует очередь. Если Ollama/модель недоступна, подборка продолжает работать по play count и Last.fm. Последовательность, время суток и настроение локальной модели влияют на причины/ранжирование, если нужные модели доступны. Пропуск до 30 секунд, дослушивание, лайк и дизлайк сохраняются в `wave_signals`.

Обложки сохраняются в `cache/covers/`; повторные запросы используют локальные файлы. Список библиотеки виртуализирован: в DOM отображается только видимый диапазон треков.

### Навигация и управление

В шапке доступны библиотека, «Моя волна», подборка недели, исполнители и статистика; выбранный раздел сохраняется в браузере. Глобальный поиск с автодополнением ищет треки, исполнителей и альбомы. Мини-плеер позволяет переключать треки, управлять громкостью и перематывать запись. Горячие клавиши: `Пробел` — play/pause, `←`/`→` — перемотка на 5 секунд, `Ctrl+←`/`Ctrl+→` — предыдущий/следующий трек, `W` — «Моя волна», `/` — поиск, `M` — mute, `F` — fullscreen.

### Подборка недели

Кнопка «Подборка недели» показывает отдельные вкладки с синглами и альбомами за последние 7 дней от артистов библиотеки и похожих исполнителей Last.fm. Deezer используется как каталог свежих релизов, а Last.fm-чарты, теги и при наличии `nomic-embed-text` помогают ранжировать их по вкусу. Ответ кэшируется локально в `.tools/weekly_cache.json` на 6 часов; «Обновить» принудительно выполняет новый запрос. «Сохранить в библиотеку» пока только помечает релиз в браузере и не скачивает аудио.

### Внешний audio downloader (необязательно)

`backend.audio_fetcher.AudioFetcher` запускает `tools/audiodl.exe`, если пользователь отдельно добавил доверенный бинарник. Он не поставляется с проектом и не подключён к UI. Используйте только для файлов, которые разрешено скачивать; операции и ошибки записываются в `.tools/audio_fetcher.log`.

### Разработка и проверки

```powershell
.\venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\venv\Scripts\python.exe -m pytest
.\venv\Scripts\python.exe .tools\check_env.py
.\.tools\run_dev.ps1
```

Dev-сервер запускает `backend.main:app` с авто-перезагрузкой на `127.0.0.1:8000`; CORS принимает только HTTP origins с хостом `localhost` или `127.0.0.1` (порт может быть любым).

Подробности: [список функций и API](docs/features.md), [решение типичных проблем](docs/troubleshooting.md).

## 3. Как это работает

```
ID3 (mutagen) → YouTube search "{artist} {title} official video"
        → nomic-embed-text ранжирует кандидатов
        → deepseek-r1:8b выбирает ОДИН клип или null
        → есть клип?  YouTube IFrame (видео + звук с YouTube)
        → нет?        Deezer → MusicBrainz/Cover Art Archive
                      → llava сверяет картинку
                      → иначе встроенный APIC, иначе градиент
```

Кэш: `cache/matches.json`. Повторное воспроизведение мгновенное.  
Кнопка **Обновить клипы** пересчитывает все треки (`force=true`).

Горячие клавиши указаны в разделе [Навигация и управление](#навигация-и-управление).

### Проверка и замена edited-треков

1. Нажмите **Качество** → **Просканировать библиотеку**. Детектор проверяет метаданные и битрейт, а MusicBrainz используется для канонической длительности; сервис ограничивает частоту запросов, поэтому большая библиотека может проверяться долго.
2. Нажмите **Найти кандидатов** у нужного трека, проверьте официальный YouTube-канал, длительность и название, затем явно подтвердите замену.
3. Функция скачивает только HTTPS-ссылки YouTube, ограничивает размер аудио 50 МБ и проверяет длительность с допуском 3%. Старый файл сохраняется в `archive/censored/`; новый файл устанавливается как Opus.
4. Массовая замена доступна только после отдельного подтверждения и выбирает первый подходящий официальный результат. Проверяйте список кандидатов вручную, если важна точность конкретной версии.

Список детектора сохраняется в `.tools/suspect_tracks.json`, результаты MusicBrainz кэшируются в `.tools/musicbrainz_durations.json`, действия записываются в `.tools/uncensored_replacements.log`.

## 4. Примеры

### Кино — Группа крови (клип есть)

1. Файл вроде `Кино - Группа крови.mp3` (теги `artist=Кино`, `title=Группа крови` или разбор имени).
2. Запросы к YouTube: `Кино Группа крови official video` / `официальный клип`.
3. Среди кандидатов — официальный ролик (часто канал артиста / Moroz / «official video»).
4. Эмбеддинги поднимают его в топ-5, deepseek возвращает `video_id`.
5. В плеере бейдж **КЛИП**, играет встроенный YouTube, локальный `<audio>` молчит.

### Редкий трек без клипа

Например, домашний demo-запис `Северная комната - Черновик 14.flac`.

1. YouTube не даёт ролика с «official video», совпадающего по смыслу.
2. deepseek (или эвристика) возвращает `null`.
3. Deezer/MusicBrainz, скорее всего, тоже пустые.
4. Если в файле есть APIC — берём её; иначе градиентный плейсхолдер с именем трека.
5. Бейдж **ОБЛОЖКА** / **ПЛЕЙСХОЛДЕР**, играет локальный файл.

## 5. Почему FastAPI, а не Node

- `mutagen` — эталон для ID3/FLAC/MP4, нативно Python.
- Ollama и httpx хорошо ложатся на `asyncio`.
- Один интерпретатор, один `venv`, один `run.bat`.

## 6. Ярлык и окно без браузера

1. Один раз запустите **`install_shortcut.bat`** — на рабочем столе и в «Пуск» появится значок **Kurymdyk**.
2. Ярлык открывает **`start_app.bat`**: поднимает сервер (если ещё не запущен) и окно Edge/Chrome в режиме `--app=` — **без адресной строки**.
3. Либо в самом плеере (Chrome/Edge): кнопка **«На рабочий стол»** / меню браузера **«Установить Курымдык»** — PWA `display: standalone`.

Сервер по-прежнему нужен (`run.bat` или ярлык сам его стартует). Ollama — как раньше.

---

## 7. Замечания

- Нужен интернет для поиска клипов/обложек и для YouTube IFrame. Сами mp3 никуда не уходят: стримятся только в ваш браузер с `127.0.0.1`.
- Часть роликов VEVO запрещает эмбед — плеер автоматически откатывается на локальное аудио.
- MusicBrainz просит осмысленный User-Agent и не чаще 1 запроса/сек — это учтено.
- Никаких ключей OpenAI / YouTube Data API / Genius и т.п.

## 8. Запуск как приложение

### Как запускать

- **`start_app.bat`** — основное: splash 2–5 сек, затем chromeless-окно Edge/Chrome (`--app`, без адресной строки), иконка в трее.
- **`run.bat`** — то же через `launch.py`. Логи uvicorn в `cache/server.log`.
- **`run.bat --debug`** — как раньше: консоль с логами uvicorn, обычный браузер.

Ярлык на рабочем столе (`install_shortcut.bat`) указывает на `start_app.bat` и иконку `frontend/icons/kadr.ico`.

### Splash

Пока поднимается сервер, открывается заставка Курымдык со строкой «Запускаю Ollama…» → «Запускаю сервер…» → «Загружаю библиотеку…» → «Готово». Если за 30 секунд `/api/health` не ответил — ошибка и кнопка «Повторить».

### Трей

ЛКМ по иконке у часов — открыть окно. ПКМ:

- Открыть Курымдык
- Обновить клипы
- Открыть папку с музыкой
- Открыть папку кэша
- Показать логи
- **Выход** — останавливает сервер

Крестик chromeless-окна **не** гасит сервер: плеер остаётся в трее.

Повторный запуск ярлыка, если сервер уже жив, только открывает окно (второй uvicorn не стартует).

### Как полностью выйти

ПКМ по иконке в трее → **Выход**.
