# Функции Курымдык

Курымдык — локальный музыкальный плеер для Windows. Веб-интерфейс и API обслуживает FastAPI; файлы библиотеки остаются на выбранном компьютере. ИИ-запросы отправляются локальной Ollama, а Last.fm, MusicBrainz и Deezer используются только для внешних метаданных и каталогов.

## Быстрый старт

1. Установите Python 3.10 или новее и, если нужны AI-функции, Ollama.
2. Для запуска с автоматической установкой зависимостей откройте `run.bat`. Для ручного запуска команды приведены в [README](../README.md#запуск).
3. Откройте `http://127.0.0.1:8000`, нажмите **Папка…** и выберите каталог с музыкой.
4. Проверьте состояние Ollama в индикаторе шапки. Без Ollama локальное воспроизведение и эвристические рекомендации сохраняются.

Для дополнительной информации Last.fm создайте `.env` в корне проекта по примеру `.env.example` и задайте `LASTFM_API_KEY`. Ключ не нужен для локального воспроизведения.

## Интерфейс

### Библиотека, поиск и мини-плеер

- Библиотека сканирует выбранную папку и показывает метаданные треков; список виртуализирован для экономии DOM и памяти.
- Поиск в шапке группирует совпадения по трекам, исполнителям и альбомам. Ввод обрабатывается с задержкой, чтобы не перерисовывать результаты на каждый символ.
- Навигация по разделам и последний выбранный раздел сохраняются в `localStorage`.
- Нижний мини-плеер управляет воспроизведением, очередью, перемоткой, громкостью и избранным. Избранное — локальная отметка; она сама по себе не скачивает аудио.
- Клавиши: `Пробел` — play/pause; `←`/`→` — перемотка на 5 секунд; `Ctrl+←`/`Ctrl+→` — предыдущий/следующий трек; `W` — включить волну; `/` — перейти к поиску; `M` — mute; `F` — полноэкранный режим.

### Клип и обложка

При разрешении трека приложение ищет подходящий YouTube-клип, локально ранжирует кандидатов и, если ролик не подходит или не найден, показывает обложку либо плейсхолдер. Для обложек проверяются встроенное изображение, локальный кэш, Deezer и MusicBrainz/Cover Art Archive. Повторная загрузка уже сохранённых обложек не требуется.

### Моя волна

Волна формирует непрерывную очередь преимущественно из локальной библиотеки: ориентировочно 60% часто слушаемого и 40% редкого, давно не включавшегося или похожего по вкусу. Учёт Last.fm и эмбеддингов улучшает подбор, если соответствующие сервисы доступны. Эмбеддинги сохраняются в `cache/stats.sqlite3`, генерируются пакетами в фоне и проверяются на новые треки раз в сутки после первого запуска волны. При недоступности Ollama очередь остаётся работоспособной на эвристиках.

Кнопки реакции влияют на сигналы волны: ранний пропуск снижает оценку, дослушивание повышает её, лайк усиливает положительный сигнал, дизлайк — отрицательный.

### Подборка недели и новинки

- **Подборка недели** разделяет свежие треки и альбомы, отбирает релизы артистов библиотеки и похожих исполнителей и фильтрует локальные записи.
- **Новые треки / Новые альбомы** находятся в панели исполнителей и показывают свежие релизы Deezer. Кнопка обновления запускает новый поиск.
- Данные подборки кэшируются на шесть часов в `.tools/weekly_cache.json`.
- Ссылки открывают страницу сервиса. **Сохранить в библиотеку** только отмечает элемент в интерфейсе: аудио не скачивается.

### Профиль исполнителя

Откройте исполнителя из библиотеки или найдите его через глобальный поиск. Профиль объединяет локальные треки, биографию, изображение, теги, похожих артистов и топ-треки Last.fm, а также недавние релизы MusicBrainz, когда найден MusicBrainz ID. Профиль не загружает коммерческие записи в библиотеку.

### Статистика

Статистика сохраняет прослушивание после более чем 30 секунд воспроизведения в локальной SQLite-базе `cache/stats.sqlite3`. Страница показывает периоды день/неделя/месяц/всё время, топ артистов и треков, активность по дням и часам и доступные жанровые теги Last.fm. Историю можно экспортировать в CSV.

### Проверка качества / замена edited-треков

Кнопка **Качество** сканирует библиотеку на ключевые слова в метаданных, низкий битрейт и сокращённую длительность. Поиск кандидатов использует yt-dlp; перед одиночной заменой пользователь должен проверить название, канал и длительность и подтвердить действие. Ограничение размера — 50 МБ. Исходник сохраняется в `archive/censored/`, новый файл обновляет локальные индексы. Массовая замена требует отдельного подтверждения; проверяйте предложенные версии до запуска.

## API для локальных интеграций

API доступен на `http://127.0.0.1:8000`; `/api/docs` показывает интерактивную схему.

| Возможность | Маршрут |
|---|---|
| Состояние приложения | `GET /api/health` |
| Сканирование библиотеки | `POST /api/scan` |
| Треки библиотеки | `GET /api/library` |
| Профиль артиста | `GET /api/artist/{name}` |
| Очередь волны | `GET /api/wave/queue?count=10` |
| Реакция на трек волны | `POST /api/wave/signal` |
| Подборка: треки / альбомы | `GET /api/weekly/tracks`, `GET /api/weekly/albums` |
| Сводка прослушиваний | `GET /api/stats/summary` |
| CSV истории | `GET /api/stats/export.csv` |
| Сканирование качества | `GET /api/uncensored/scan` |

Сканирование библиотеки:

```powershell
$body = @{ path = 'D:\Music' } | ConvertTo-Json
Invoke-RestMethod -Method Post -Uri http://127.0.0.1:8000/api/scan `
  -ContentType 'application/json' -Body $body
```

API не предназначен для публикации в локальной сети: CORS разрешает только HTTP-origin `localhost` и `127.0.0.1`. Выбор папки позволяет серверу читать файлы по этому локальному пути.

## Локальные данные

- `cache/` — обложки, индексы, ошибки и статистика SQLite.
- `.tools/lastfm_cache/` — ответы Last.fm (24 часа; ограниченный stale fallback до 7 дней).
- `.tools/weekly_cache.json` — подборка на шесть часов.
- `.tools/suspect_tracks.json` и `.tools/uncensored_replacements.log` — результаты сканирования качества и журнал замен.
- `.env` — локальные ключи; не добавляйте его в Git.
