# Настройка браузера для Курымдык

## Расширения, которые МЕШАЮТ караоке
- uBlock Origin — может блокировать Web Audio API
- Privacy Badger — блокирует getUserMedia
- AdGuard — блокирует медиа-запросы
- Ghostery — блокирует всё подряд
- Любые VPN-расширения — мешают подключению к 127.0.0.1

## Что делать
1. Открой браузер → Settings → Extensions
2. Найди эти расширения
3. Для каждого выбери «Настройки для сайта» → добавь исключение для http://127.0.0.1:8000
4. ИЛИ отключи их совсем на время работы с плеером

## Проверка что караоке работает
1. Открой http://127.0.0.1:8000
2. F12 → Console
3. Нажми «Караоке: Вкл»
4. Должно появиться: [karaoke] context state: running
5. Если state: suspended — браузер блокирует, кликни по странице ещё раз
